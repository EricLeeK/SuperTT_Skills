# SuperTT Skills

SuperTT Skills is an open-source repository for high-quality Codex skills created by Super TT.

This repository will grow over time as more reusable skills are added. Each skill is designed to capture a practical workflow, learning method, or development pattern that can help people work more effectively with AI coding agents.

## Included Skills

### Vibe Coding Tutor

`vibe-coding-tutor` is an AI-era codebase learning coach. It helps learners understand unfamiliar codebases by choosing the right scale of exploration, mapping project structure, tracing data flow, identifying contracts and extension points, and practicing with AI-assisted implementation loops.
